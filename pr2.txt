Replacement Program Requirements: Euler Theorem Prover in Prolog for Children and Web

Project Aim

Create a child-understandable Prolog theorem prover that replaces the Gaussian Theorem Prover style with an Euler/integration-based theorem prover.

It should accept algorithmic or summation-style inputs such as:

sum(i, 1, n, i^2).
sum(i, 1, n, (i+2)^2).
sum(i, 1, n, i^3 + 0.5).
algorithm(sum_squares_shifted).

and produce:

closed_form(...)
proof_steps(...)
child_explanation(...)
web_visualisation(...)

⸻

1. Core Difference from Gaussian Theorem Prover

The Gaussian Theorem Prover discovers formulas by fitting patterns, matrices, recurrence tables, or Gaussian elimination.

The Euler Theorem Prover should instead discover formulas by:

sum → staircase
staircase → integral
integral → area
area + endpoint corrections → closed form
closed form → simplified theorem

So the main reasoning pipeline is:

parse_spec(Input, Spec).
detect_function(Spec, F).
integrate_function(F, Integral).
apply_euler_correction(F, Correction).
simplify(Integral + Correction, ClosedForm).
verify_by_testing(Spec, ClosedForm).
explain_to_child(Spec, ClosedForm, Explanation).

  "The final formula is n(n+1)(2n+1)/6."

Example 2

Input:

sum(i, 1, n, (i+2)^2).

Expected expanded form:

(i+2)^2 = i^2 + 4*i + 4

Output should use known sums:

sum(i^2) + 4*sum(i) + 4*sum(1)

Closed form:

n*(n+1)*(2*n+1)/6 + 2*n*(n+1) + 4*n

Then simplified if possible.

Child explanation:

First we open the bracket.
Then we add the square part, the line part, and the constant part.
Euler's method lets each part become a formula.

Example 3

Input:

sum(i, 1, n, i^3 + 0.5).

Output:

closed_form((n*(n+1)/2)^2 + n/2).

Explanation:

We split the problem into two easier sums.
The cube part becomes the square of the triangular number.
The 0.5 part is added n times, so it becomes n/2.

6. Integration-Based Algorithm Pipeline

The required theorem-proving pipeline is:

euler_pipeline(Input, Output) :-
    parse_input(Input, SumSpec),
    normalise_sum(SumSpec, Normalised),
    expand_polynomial_sum(Normalised, Expanded),
    split_sum_terms(Expanded, Terms),
    prove_each_term_by_euler(Terms, TermProofs),
    combine_term_proofs(TermProofs, Combined),
    simplify(Combined, ClosedForm),
    verify_formula(SumSpec, ClosedForm),
    child_explanation(TermProofs, Explanation),
    package_output(ClosedForm, TermProofs, Explanation, Output).

⸻

7. Integration Rules

integrate(X, X, X^2/2).

integrate(C, X, C*X) :- number(C).

integrate(A-B, X, IA-IB).
integrate(C*A, X, C*IA) :- number(C).

14. README Description

Euler Theorem Prover is a child-friendly Prolog and web theorem prover that derives closed forms for sums by using Euler-style integration, Euler-Maclaurin correction terms, polynomial expansion, and symbolic simplification.
Unlike the Gaussian Theorem Prover, which discovers formulas through pattern tables and Gaussian elimination, this system explains sums as areas, curves, staircases, endpoint corrections, and symbolic integration.
